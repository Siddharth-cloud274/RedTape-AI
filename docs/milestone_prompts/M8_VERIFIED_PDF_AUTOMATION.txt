PHASE C — PDF INSPECTION ENGINE
====================================================

Use PyMuPDF.

Inspect the official PDF to determine:

- Number of pages
- Page dimensions
- Orientation and rotation
- Embedded text
- Existing AcroForm widgets
- Input areas without widgets
- Tables
- Checkboxes
- Signature areas
- Official instructions
- Document checklist pages

Support two template types:

TYPE A — FILLABLE PDF:
Use the official AcroForm widgets and their
actual field names.

TYPE B — STATIC PDF:
Use a manually verified page-coordinate mapping
to position text on the existing official PDF.

Never assume a form is fillable merely because
it contains blank lines.

For static templates:

1. Render the original PDF to page images.
2. Inspect each page visually.
3. Identify writable input areas.
4. Create explicit coordinate mappings.
5. Test placement using synthetic data.
6. Re-render the generated document.
7. Verify position, alignment and readability.
8. Refuse export if critical fields overlap
   labels, instructions or other content.

Do not use guessed coordinates in production
template mappings.

Do not use unrestricted OCR unless necessary.

Preserve the official document's original text,
structure, pages and instructions.

Determine the real mapping based on the
actual PDF structure.

Do not infer document field coordinates
from Gemini-generated text alone.
